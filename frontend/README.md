# TinyFarm-G486 Frontend

## Setup

1. [Install Node.js](https://nodejs.org/en/download) if not already done
2. Go to the `frontend` directory
3. Run `npm i`

## Launch

### Development with hot reload

Run `npm run dev` in the `frontend` directory

### Production

Run `npm run start` in the `frontend` directory

## Auto-formatting

### VSCode

1. Install the `Prettier` extension
2. To auto-format your code, in a `.html`, `.css` or `.js` file, choose one of the following options:
    - Press `Alt + Shift + F` on Windows
    - Press `Ctrl + Maj + I` on Linux
    - Right-click and choose `Format document`
